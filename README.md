Backend RESTful API designed to manage and monitor fuel dispensing operations, service station inventory, and daily transaction logs. Built with **Node.js**, **Express 5**, and **Firebase Admin SDK**.

---

## 🚀 Core Functionalities

- **Dispense Logging:** Endpoints to record fuel volume, pump ID, fuel type, and timestamps.
- **Firebase Cloud Firestore Integration:** Real-time data synchronization and persistence.
- **CORS & Environment Security:** Configured with `cors` and `dotenv` for secure multi-environment deployments.
- **Modular MVC Architecture:** Separated routes, controllers, and services.

---

## 🛠️ Stack

- **Language & Runtime:** JavaScript (Node.js)
- **Framework:** Express.js 5
- **Cloud Backend:** Firebase Admin SDK (Cloud Firestore)

---

## ⚙️ Local Setup

```bash
git clone https://github.com/Jmrm16/Estacion-.git
cd Estacion-
npm install
# Configure serviceAccountKey.json and .env
node server.js
```
